# 📚 StudyAssist

Free AI study helper. Upload or paste a syllabus and get, for every chapter:
chapterwise notes, 2 / 5 / 10 mark questions with answers, and a mindmap for every topic.

**Use it:** open the GitHub Pages link of this repository.

**How it works:** 100% in your browser. You paste your own free Google Gemini API key
(https://aistudio.google.com/apikey) in ⚙ Settings. The key and your study material are stored only in your
browser and are sent only to Google (or Anthropic if you choose Claude). There is no server and no cost.

Files: `index.html` and `app.js` (no build step).
